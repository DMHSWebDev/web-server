1. The five arithmetic operators

Division always produces a decimal when numbers do not divide evenly. Modulus (%) gives the remainder, not the quotient. 

let a = 23;
let b = 5;

a + b   // 28
a - b   // 18
a * b   // 115
a / b   // 4.6
a % b   // 3   <-- remainder


            

                Remember: 23 / 5 is 4.6, but 23 % 5 is 3.
                The quotient is 4 and the remainder is 3 — modulus returns the remainder.
            

        


        
        

            
2. Modulus finds even and odd

            

                Any number % 2 can only be 0 or 1. That makes it the standard
                even/odd test. Type a number and watch it work.
            



if (num % 2 === 0) {
    // even
} else {
    // odd
}


            

                
                
                
            

            


            

                Remember: the remainder is always smaller than the divisor.
                Anything % 5 can only be 0, 1, 2, 3, or 4.
            

        


        
        

            
3. The + problem

            

                + does two jobs: it adds numbers, but it joins
                if either side is text. Every other arithmetic operator forces numbers.
                This matters because form input is always a string.
            



'8' + 2    // '82'   joined, not added
'8' - 2    // 6      '-' has no text meaning
'8' * 2    // 16
Number('8') + 2   // 10   the fix


            

                
                
                
                
                
            

            


            

                Remember: .value from an input is a string.
                Wrap it in Number() or parseInt() before doing math.
            

        


        
        

            
4. Prefix vs. postfix increment

            

                Both x++ and ++x raise the variable by one.
                The difference is what the expression hands back.
            



let x = 5;
let a = x++;   // a is 5, x is 6   (hand back, then add)

let y = 5;
let b = ++y;   // b is 6, y is 6   (add, then hand back)


            
            


            

                Remember: the ++ goes first, it happens first.
                On a line by itself the two forms are identical.
            

        


        
        

            
5. Compound assignment

            

                A shortcut for doing math on a variable and storing the result back in it.
                x += 5 is the same as x = x + 5.
            


            

                
ShortcutLonghand

                
x += 5x = x + 5

                
x -= 5x = x - 5

                
x *= 5x = x * 5

                
x /= 5x = x / 5

                
x %= 5x = x % 5

            


            
            


            

                Remember: x++ and x += 1 do the same thing.
            

        


        
        

            
6. = vs == vs ===

            

                One equals sign assigns. Two or three compare.
                A single = inside an if is a classic bug: it stores a
                value and then treats that value as the condition.
            



let level = 2;

level = 5      // assigns 5 — the condition is "truthy", always runs
level == '5'   // true  — compares value only, converts the type first
level === '5'  // false — compares value AND type
level === 5    // true


            
            


            

                Remember: use === for comparisons. It checks the
                type too, which catches the string-vs-number mistakes from Card 3.
            

        


        
        

            
7. Naming and best practices (1.2)

            

                Names must start with a letter, _, or $ — never a digit.
                No spaces or hyphens, and no reserved keywords. Variables use camelCase;
