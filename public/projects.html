Server Extensions

Authentication and Access

  • Password-based login checked against a server-side environment variable
  • Session-based authentication with optional seven-day "Remember me"
  • Logout destroys the active session
  • Dashboard, guestbook page, and guestbook API require login
  • Login status endpoint for the frontend

Guestbook API

  • Guestbook entries persist in a JSON data file
  • Authenticated endpoints list, add, and clear entries
  • Validates names and messages, normalizes whitespace, and filters profanity
  • Each entry receives a unique ID and timestamp; storage keeps the latest 50

Monitoring and Request Controls

  • Rate limit of 100 requests per IP every 10 seconds
  • Request method and path logged to the console and a server log file
  • Visitor count for the home and projects pages, exposed through a stats endpoint
  • Static pages served with extensionless HTML URLs
